# Rock Paper Scissors Game 🎮

A console-based **Rock Paper Scissors game developed in C++**.

The game allows the player to choose the number of rounds and compete against the computer. The computer generates its choice randomly, and the program determines the winner of each round and keeps track of the overall game results.

## Features

* Choose the number of rounds (1–10).
* Player chooses between:

  * Stone
  * Paper
  * Scissors
* Computer makes a random choice.
* Determine the winner of each round.
* Track player wins, computer wins, and draws.
* Display the result of every round.
* Display the final game statistics and overall winner.
* Visual feedback using different console colors for wins, losses, and draws.
* Option to play again after the game ends.
